    1. Resolve project root: `Path(__file__).resolve().parent.parent.parent` (same pattern as oauth.py)
    2. Load channel_config.json from `channels/{channel}/channel_config.json` to read defaults:
       - `youtube.upload_defaults.category` (string) — category name, not categoryId
       - `youtube.upload_defaults.language` (string)
       - `defaults.privacy` (only if `privacy` param not set)
       - `defaults.license` (string: "youtube" or "creativeCommon")
       - `defaults.embed` (boolean)

       - `snippet.title`: use `video_path.stem` as the title (metadata.py in future plans overrides this per D-01)

       - `status.publishAt`: from `publish_at` param (only include if non-None)
       - `status.madeForKids`: False
       - `status.selfDeclaredMadeForKids`: False
       - `status.embeddable`: from config or True
       - `status.license`: from config or "youtube"
    4. If `publish_at` is set and `privacy` is "public", set `privacy` to "private" in the body (YouTube requires scheduled videos to be private)
    5. Pre-flight quota check per D-11:
       - Create `QuotaBudget()` instance
       - Check `quota.can_consume("youtube_upload", 1)`
       - If not: print `"Remaining upload quota: {remaining}/6 today. Resets at midnight UTC."` per D-12, log warning, return None
       - Else: print remaining quota info
    6. Get authenticated service: `youtube = get_authenticated_service(channel)`
    7. Create `MediaFileUpload(video_path, chunksize=256*1024, resumable=True)`
    8. Call `youtube.videos().insert(part="snippet,status", body=body, media_body=media)` to get request
    9. Upload loop with exponential backoff:
       - max_retries = 5
       - For each attempt:
         - Try `status, response = request.next_chunk()`
         - If `status` is not None, log progress: `"Upload progress: {int(status.progress() * 100)}%"`
         - If `response` is not None, upload is complete — break
         - On `HttpError`:
           - If status is 403 and "quotaExceeded" in str(e): per D-13, print quota exceeded warning, log error, call `quota.consume("youtube_upload", 1600)` (mark the quota as consumed since the API used it), return None
           - If status in (500, 502, 503, 504) and attempt < max_retries - 1:
             - sleep_time = (2 ** attempt) + random.uniform(0, 1)
             - print retry message, time.sleep(sleep_time)
             - continue
           - Else: raise
    10. On successful upload:
        - Call `quota.consume("youtube_upload")` per D-19
        - video_id = response["id"]
        - If `thumbnail_path` is provided: call `upload_thumbnail(channel, video_id, thumbnail_path)`
        - Return video_id string
    11. Wrap the entire function body in a try/except that catches broad exceptions, logs them, and returns None

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → uploader | User-provided file paths cross into the process at argument parsing |
| uploader → YouTube API | Video file data crosses from local disk to Google's servers over HTTPS |
| uploader → QuotaBudget | Quota state file accessed with file locking from multiple processes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Denial of Service | upload_video quota check | mitigate | Pre-flight `QuotaBudget.can_consume()` before upload begins; catch `HttpError(403, "quotaExceeded")` mid-upload with graceful return None |
| T-06-02 | Tampering | upload_video file path | mitigate | Validate `video_path` exists and is a file via `Path.exists()` and `Path.is_file()` before upload; catch `FileNotFoundError` |
| T-06-03 | Spoofing | get_authenticated_service | accept | Delegated to oauth.py (Phase 5) — OAuth 2.0 token lifecycle handles authentication. Uploader trusts the authenticated service provided by that module. |
| T-06-04 | Denial of Service | resumable upload loop | mitigate | Exponential backoff with max 5 retries on server errors (500/502/503/504); non-retryable errors raised immediately |
| T-06-05 | Information Disclosure | CLI error messages | mitigate | Log full traceback at DEBUG level; print user-safe messages (e.g., "Upload failed: API quota exceeded") at console |
| T-06-06 | Tampering | quota state file | mitigate | QuotaBudget uses `portalocker` with exclusive file locks on write to prevent concurrent corruption (already implemented in quota.py) |
</threat_model>
