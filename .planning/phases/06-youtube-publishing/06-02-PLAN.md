def generate_metadata(channel: str, script_data: dict, brain_data: dict) -> dict:

        script_data: The active_script.json content (scenes, hooks, CTA structure)

### Function 1: `generate_chapters(scene_checkpoints: list[dict]) -> str`

Reads scene-level checkpoints and builds the YouTube-style chapter description string.

```python
def generate_chapters(scene_checkpoints: list[dict]) -> str:
    """
    Generate YouTube chapter markers from scene-level checkpoint data.

    Args:
        scene_checkpoints: List of checkpoint dicts with keys:
            scene_id (str, e.g. 'scene_01'),
            scene_number (int, from scene_id),
            section_name (str, from script_data), OR
            output dict with at least 'section_name' key

            When scene output contains a 'section_name' or 'title' key, use that.
            Otherwise derive from scene_id.

    Returns:
        Formatted chapter string like:
        00:00 - Intro
        01:30 - Main Content
        05:15 - Conclusion

        If no checkpoints or all are empty: returns empty string.
    """
```

**Implementation:**
1. Sort checkpoints by scene number (extracted from `scene_id` like `scene_01` → 1)
2. Use `CheckpointManager` from `agent_core.core.checkpoint` — instantiate with default path, find checkpoints by pipeline_id when available
3. Accumulate running timestamp — each scene's duration from `duration_estimate` in checkpoint output or use 90s default if not available
4. Format as `MM:SS` with leading zeros — `00:00` for first scene
5. First scene label is always the scene's section_name or "Intro"
6. If chapters total would exceed 5000 chars (YouTube limit), truncate to last complete chapter
7. Return formatted string; if empty, return ""
8. **Do NOT use CheckpointManager directly for the CLI pipeline_id path** — accept checkpoints as pre-loaded list of dicts, keeping the function testable and decoupled

### Function 2: `build_video_snippet(metadata: dict, chapters: str, channel_config: dict) -> dict`

Assembles the complete YouTube video snippet dict combining LLM metadata + chapters + channel defaults.

```python
def build_video_snippet(metadata: dict, chapters: str, channel_config: dict) -> dict:
    """
    Build the full video snippet dict for the YouTube API videos().insert() call.

    Args:
        metadata: Output from generate_metadata() — dict with title, description, tags, category_id
        chapters: Output from generate_chapters() — formatted chapter string
        channel_config: Parsed channel_config.json dict

    Returns:
        dict structured for YouTube API videos().insert(part="snippet,status", body=...)
    """
```

**The snippet dict structure (Python dict, ready to be passed to youtube.videos().insert):**

```python
{
    "snippet": {
        "title": metadata["title"],
        "description": _build_full_description(metadata["description"], chapters, channel_config),
        "tags": metadata["tags"],
        "categoryId": metadata["category_id"],
        "defaultLanguage": channel_config.get("youtube", {}).get("upload_defaults", {}).get("language", "en"),
        "defaultAudioLanguage": channel_config.get("youtube", {}).get("upload_defaults", {}).get("language", "en"),
    },
    "status": {
        "privacyStatus": channel_config.get("defaults", {}).get("privacy")
                          or channel_config.get("youtube", {}).get("upload_defaults", {}).get("visibility", "private"),
        "publishAt": None,  # populated by scheduler/uploader
        "selfDeclaredMadeForKids": False,
        "embeddable": channel_config.get("defaults", {}).get("embed", True),
    },
    "recordingDetails": {
        # location and date — can be enriched by uploader if needed
        "location": {"latitude": 0.0, "longitude": 0.0, "altitude": 0.0, "locationDescription": ""},
        "recordingDate": datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S.000Z"),
    }
}
```

**Internal helper `_build_full_description(base_desc, chapters, channel_config)`:**
1. Start with `base_desc` from LLM
2. If `chapters` is non-empty, append:
   ```
   
   ---
   Chapters:
   {chapters}
   ```
3. Append CTA footer (per D-04 reading channel config for CTA strategy):
   ```
   
   ---
   {CTA_text from brain.json monetization.cta_strategy or default "Subscribe for more!"}
   ```
4. Return full string (YouTube description max is 5000 chars — warn if exceeds via logger)

### CLI entry point

Add a `main()` function with argparse that supports:

```python
def main():
    parser = argparse.ArgumentParser(description="Generate YouTube video SEO metadata")
    parser.add_argument("--channel", required=True, help="Channel name (e.g. ChannelA)")
    parser.add_argument("--dry-run", action="store_true", help="Preview metadata without persisting")
    parser.add_argument("--description", help="Override auto-generated description")
    parser.add_argument("--chapters-file", type=Path, help="Path to custom chapters file (overrides auto-generation)")
    parser.add_argument("--pipeline-id", help="Pipeline ID for chapter checkpoint reading")
    args = parser.parse_args()
```

**Flow:**
1. Load `channel_config.json` and `brain.json` for the channel
2. Find the active script: `channels/{channel}/active_production/script.json` (fallback: warn and use empty dict)
3. Call `generate_metadata(channel, script_data, brain_data)` → metadata
4. If `--description` provided, override `metadata["description"]`
5. Generate chapters:
   - If `--chapters-file` provided, read from that file
   - Else if `--pipeline-id` provided, use `CheckpointManager.list_checkpoints(pipeline_id)` to find scene checkpoints
   - Else use `CheckpointManager` to discover latest pipeline in `data/checkpoints/`
   - Call `generate_chapters(scene_checkpoints)` 
6. Call `build_video_snippet(metadata, chapters, channel_config)` → snippet
7. If `--dry-run`: print `json.dumps(snippet, indent=2)` to stdout, exit
8. Else: persist metadata to `channels/{channel}/active_production/metadata.json` and print snippet
9. Return the snippet dict for programmatic callers

Also add a `generate_full_metadata(channel: str, pipeline_id: str | None = None, description_override: str | None = None, chapters_file: Path | None = None) -> dict` convenience function that wraps the full flow for programmatic use by `uploader.py`.
