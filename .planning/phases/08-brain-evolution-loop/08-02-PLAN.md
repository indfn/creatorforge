<objective>
**Refactor the scoring engine to load per-channel brain.json when a channel is specified, enabling per-channel learning weights to influence topic scores.**

**Purpose:** Per D-05 and D-06, the scoring engine must support optional per-channel brain context. When `channel` is provided, `load_brain_context` reads `channels/{Name}/brain.json` instead of the global `agent_core/data/agent-brain.json`. This allows the brain evolution loop (ANALYTICS-04) to produce per-channel weight updates that the scoring engine actually uses.

**Output:**
- Modified `agent_core/scoring/engine.py` — channel-aware `load_brain_context()`, channel-passthrough `score_topic()`
- Updated `tests/test_scoring/test_engine.py` — coverage for channel-aware loading and backward compatibility
</objective>
